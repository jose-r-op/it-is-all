# IT IS ALL - E-commerce

Proyecto de comercio electrónico para la marca de streetwear gótico y darkwear **IT IS ALL**, desarrollado con Angular 19.

## Servidor de desarrollo

Para iniciar el servidor local de desarrollo:

```bash
ng serve
```

Navega a `http://localhost:4200/`. La aplicación se recarga automáticamente al modificar los archivos.

## Compilación para producción

Para compilar el proyecto:

```bash
ng build
```

Los artefactos compilados se almacenan en el directorio `dist/`.

## Características implementadas

- Catálogo de prendas darkwear dinámico conectado a API/JSON.
- Filtros interactivos por categoría de prendas.
- Selector interactivo de tallas por prenda.
- Bolsa de compras / Carrito lateral interactivo con cálculo de totales.
- Galería y carrusel de «Vista Rápida» en perspectiva continua.
- Sistema de notificaciones toast.
